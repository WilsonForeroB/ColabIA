# ColabIA — Actividades de Inteligencia Artificial Práctica

Repositorio de actividades para un curso de **Inteligencia Artificial** usando Google Colab y modelos de lenguaje locales. Cada actividad es un notebook `.ipynb` listo para ejecutar celda a celda, sin necesidad de instalar nada en tu computadora.

## 🚀 Cómo empezar

1. Abre el `README.md` de la actividad que quieras explorar
2. Descarga el notebook `.ipynb` correspondiente
3. Ábrelo en [Google Colab](https://colab.research.google.com) con GPU T4 activa
4. Ejecuta las celdas de arriba a abajo

Cada actividad incluye instrucciones detalladas, preguntas de reflexión y retos opcionales.
